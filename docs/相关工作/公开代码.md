## 下载

```bash
bash 相关工作/下载公开代码.sh
```

脚本以 `--depth 1` 克隆上述 12 个仓库至 `相关工作/codes/`，支持已存在仓库跳过和克隆失败汇总；不会删除或覆盖已有目录。许可状态、论文对应关系与分支以 [TSV 清单](公开代码仓库.tsv) 为准。公开仓库不等于已安装依赖、已运行或已复现论文结果。
