## 2. 术语体系与边界

<a id="s2-1"></a>

### 2.1 AutoML 的狭义与广义定义

狭义 **AutoML** 通常指：给定数据集、目标和算力预算，自动选择数据处理步骤、模型族、超参数并输出预测器。常用表述是 **CASH：Combined Algorithm Selection and Hyperparameter Optimization**。广义 AutoML 扩展到特征构建、训练资源配置、评估方案、神经架构、集成、模型压缩与部署决策。

机器学习人工流程可拆解为：

```text
业务目标 → 数据定位/权限 → 数据理解 → 任务定义/指标
     → 数据切分 → 清洗/编码/特征 → 模型空间设计
     → 搜索/调参/训练 → 验证/诊断 → 重训练/集成
     → 制品打包 → 部署 → 监控 → 数据或模型迭代
```

传统 AutoML 的强项通常是中间的受限步骤，Agentic AutoML 则尝试把周边的上下文理解、行动与迭代纳入闭环。[R01]–[R07]

<a id="s2-2"></a>

### 2.2 五种容易混淆的系统

| 系统范畴 | 决策变量 | 典型反馈 | 典型代表 | 不应混淆之处 |
|---|---|---|---|---|
| HPO | 学习率、深度、正则项等 | 验证损失、资源开销 | SMAC、Optuna、BOHB | HPO 不等于完整 AutoML |
| Pipeline AutoML / CASH | 预处理器、模型族和超参数 | 交叉验证性能 | Auto-WEKA、auto-sklearn | 搜索空间常预先规定 |
| NAS / AutoDL | 网络拓扑、算子、训练协议 | 验证精度、延迟 | DARTS、Auto-PyTorch | 架构权重训练与模型训练需区分 |
| ML Engineering Agent | 代码、实验计划、特征、配置 | 执行日志、训练指标、比赛打分 | AIDE、ML-Master | 开放式代码空间，风险与自由度更大 |
| Autonomous Data Science / AI Scientist | 数据探索、分析、假设、模型、报告 | 测试、任务完成度、研究评价 | R&D-Agent、DeepAnalyze、AI Scientist | 目标范围可能超出预测模型本身 |

<a id="s2-3"></a>

### 2.3 “Agent for AutoML”至少有四个层级

**L0 工具使用**：Agent 读取用户自然语言，调用已存在的 `AutoML.fit()`，生成文字报告；改变的是交互界面，不是搜索算法。

**L1 自适应编排**：Agent 根据数据分布、资源约束选择 AutoML 引擎、任务和预算；能分析错误并重新运行。

**L2 开放式方案探索**：Agent 可改变特征、验证方案、代码实现、模型族，进行实验树搜索和并行假设验证。

**L3 学习型 ML Agent**：不只靠推理时提示词执行，还通过轨迹数据、反馈/奖励、强化学习或其他策略学习，提升跨任务实验策略。[R28]–[R29]

上述层级是**本报告提出的分类框架**，并不是业界统一官方标准。

<a id="s2-4"></a>

### 2.4 “AutoML 中的 Agent”与“Agent 的 AutoML”

二者方向相反：

- **Agent for AutoML**：用 Agent 改进机器学习系统设计和实验执行。
- **AutoML for Agents**：用搜索、调参、架构优化自动寻找更好的 Agent 工作流、工具路由、提示策略或策略模型。

研究上会逐渐融合，但比较实验必须固定主要优化对象。若最终指标是 Kaggle AUC，它研究的是 ML 任务；若指标是 agent 工具调用成功率或 token 成本，则更偏向 Agent 系统自动优化。

## 3. AutoML 发展史与知识地图

| 时段 | 主导问题 | 关键思想 | 代表资料 |
|---|---|---|---|
| 早期至 2013 | 如何从大量算法与超参数组合中选优 | CASH、配置器、SMBO | Auto-WEKA [R02] |
| 2014–2018 | 如何更高效、更稳健地自动搜索 | 元特征、warm start、集成、Bandit 预算分配 | auto-sklearn、Hyperband、BOHB [R03]–[R05] |
| 2016–2021 | 如何扩展到管线、深度模型及工程框架 | 遗传管线、NAS、梯度松弛、搜索与集成组合 | TPOT、DARTS、AutoGluon、Auto-PyTorch [R06]–[R09] |
| 2021–2024 | 如何减少搜索成本并构建公平比较 | FLAML、auto-sklearn 2.0、AMLB、TabRepo | [R10]–[R13] |
| 2024–2025 | 能否让 LLM 自主开展 ML 实验 | ReAct、案例推理、规划/执行、代码树搜索 | MLAgentBench、DS-Agent、AutoML-Agent、AIDE、MLE-bench [R20]–[R32] |
| 2025–2026 | Agent 能否可迁移、可训练、可验收 | 经验记忆、研究/开发解耦、真实环境训练、逐步 RL | ML-Master、R&D-Agent、ML-Agent、DeepAnalyze [R25]–[R29] |

知识地图：

```text
                          Machine Learning Automation
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │                                                       │
  Search-centric AutoML                                  Agent-centric ML
        │                                                       │
  ┌─────┼─────────┐                        ┌─────────────────────┼──────────────────┐
  │     │         │                        │                     │                  │
 CASH  HPO       NAS                   Planning              Execution          Reflection
  │     │         │                        │                     │                  │
 auto-  BO/ASHA   DARTS                 Retrieval/CBR         Code/Tools         Logs/Eval/Memory
 sklearn BOHB      AutoDL                  │                     │                  │
  └─────┴─────┬───┘                        └───────────┬─────────┴──────────────────┘
              │                                        │
       Ensembling / Meta-learning               Agentic Experiment Loop
              │                                        │
              └────────────────┬───────────────────────┘
                               │
                  Hybrid, Verified Agentic AutoML
```

关键是，Agentic ML 的新颖性大多不在“发明了一种比 TPE 更好的参数采样器”，而在**使开放式实验行动可规划、可执行、可回溯、可继续学习**。

## 20. 术语表与附录

<a id="s20-1"></a>

### 20.1 术语表

| 缩写/术语 | 全称 | 本报告中的含义 |
|---|---|---|
| AutoML | Automated Machine Learning | 机器学习过程的自动化 |
| AutoDL | Automated Deep Learning | 深度学习模型/训练自动设计 |
| CASH | Combined Algorithm Selection and Hyperparameter Optimization | 算法选择与超参数联合优化 |
| HPO | Hyperparameter Optimization | 超参数优化 |
| NAS | Neural Architecture Search | 神经架构搜索 |
| BO | Bayesian Optimization | 贝叶斯优化 |
| SMBO | Sequential Model-Based Optimization | 序贯模型优化 |
| TPE | Tree-structured Parzen Estimator | 基于密度估计的 HPO 建议策略 |
| SMAC | Sequential Model-based Algorithm Configuration | 算法参数配置与 BO 家族 |
| SH | Successive Halving | 逐轮淘汰、分配更多训练预算 |
| ASHA | Asynchronous Successive Halving Algorithm | 异步多保真资源分配 |
| BOHB | Bayesian Optimization and HyperBand | 贝叶斯建议与多保真结合 |
| CBR | Case-Based Reasoning | 基于历史案例的推理/迁移 |
| RAP | Retrieval-Augmented Planning | 检索增强规划（AutoML-Agent） |
| OOF | Out-of-Fold | 由未在该样本上训练的模型产生的预测 |
| LLM | Large Language Model | 大语言模型 |
| Agent | 具备目标、状态、工具与反馈的执行系统 | 不只是对话接口 |
| Agentic AutoML | Agent-augmented Automated ML | Agent 负责规划、执行与反馈的自动 ML |
| MLE | Machine Learning Engineering | 机器学习工程全过程 |
| ML4AI / AI4AI | AI for AI | 用 AI 系统改进 AI 的设计/训练/评估 |
| RAG | Retrieval-Augmented Generation | 检索增强生成，可扩展为实验经验检索 |
| SLO | Service-Level Objective | 延迟、吞吐、错误率等服务目标 |
| Drift | Data/Concept Drift | 输入分布或输入到目标关系变化 |
| Regret | 后悔值 | 与目标最优策略之间的效果差距 |
| Best-so-far | 当前预算下已发现最优 | 衡量时间/成本效率 |
| Run Replay | 实验轨迹回放 | 相同数据/代码/环境重复试验 |
