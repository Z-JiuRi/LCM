# LCMAgent 实验方案草案

> **状态：待实施的实验协议。** 所有假设、门槛与方法都需要先用 pilot 验证；本文件不是实验结果。实验参数一旦用于确认性比较，应在运行前固定并随代码、配置和 commit SHA 归档。
>
> 关联：[总体架构](LCMAgent架构设计草案.md)、[代码框架](代码框架与文件结构.md)、[材料映射与决策门](材料映射与决策门.md)。本方案继承[工具链调研](../分析/LCMAgent实验数据与仿真工具链调研.md)中的 D0-D4 证据等级和数据划分原则。

## 1. 要回答的问题

实验的核心不是证明 LLM 能调用无线工具，而是检验：在相同执行器、候选模型、初始观测和测量预算下，决策策略能否用更少或更有价值的证据，在业务窗口内安全完成有益生命周期动作，并在证据不足或执行失败时正确等待、拒绝或恢复。

实验分开回答三类主张：

| 主张 | 需要的证据 | 不能由什么替代 |
|---|---|---|
| 系统正确性 | 确定性验证、epoch/契约测试、故障注入和恢复日志 | planner 自述、单元测试通过率、静态状态图 |
| 决策有效性 | 同一 episode 上，风险/进展/业务损失/证据成本的配对比较 | 只报告模型 NMSE 或 Agent 总成功率 |
| Agent 必要性 | 同执行层、同工具、同预算下，LLM 相对非 LLM 的净增益 | 和无验证器、无主动测量的弱基线比较 |

如果系统正确性成立但 LLM 没有增益，结论应落在可靠的非 LLM LCM 执行系统；不得为了保留 Agent 叙事而更换主指标。

## 2. 主用例和顺序

### 2.1 主用例：单侧波束管理

以模型选择/监测/适配为生命周期动作。绑定对象至少包括 function digest、波束码本/测量集、设备能力、场景域和校准版本；证据可来自 KPI、输入分布摘要、top-K 复核或扩大扫描。普通波束切换仍由快速无线控制器执行，慢速 lifecycle planner 不进入每时隙数据路径。

选择它作为主用例的原因是：项目综述指出波束 model selection/monitoring 和 adaptation 已有直接工作，能形成有压力的非 LLM 基线；CSI 配对不是通用架构的前提。实验既可检验有限测量下的决策，又可避免先把首版绑定到双侧事务。

数据入口只作为候选：DeepBeam 是毫米波波束测量代码/数据路线之一，DeepSense6G challenge repo 是另一候选。开跑前需确认本地实际包含的数据文件、数据使用条件、标签定义、码本语义和场景切分；当前公开代码目录和 README 本身不证明数据已下载、许可可用或基线已复现。

### 2.2 次用例：双侧 CSI 配对

CSI 用于检验主骨架在 PairManifest、latent/quantization/preprocessing 语义、双侧资源和部分提交场景下是否需要扩展。固定 encoder/decoder 候选作为已存在模型资产，不把训练算法或跨厂商互操作说成 LCMAgent 新贡献。必须同时评估重建质量、反馈开销、业务 KPI 与事务恢复；NMSE 不能替代系统收益。

先在同一控制面上回放合成配对状态和故障，再接入已核实的数据/权重与链路评价。仓库内 CsiNet 是旧 Keras/TensorFlow 代码路径，作者 README 将 only-test、训练代码、保存权重和外部数据分开；复现前要冻结输入预处理、权重哈希和运行环境，不将旧依赖并入 core。

定位、神经接收机、链路自适应只作为扩展验证；没有新的研究问题和可用真值前不承诺覆盖。

## 3. 假设与可证伪预测

| 编号 | 假设 | 主要观测 | 反证条件 |
|---|---|---|---|
| H1 | 在相同总证据预算下，成本/价值驱动的主动补测较固定周期/阈值策略提升安全进展，或在相同进展下减少成本 | safe progress、unsafe release、measurement/UE compute cost 的 Pareto 曲线 | 只降低成本但显著损害安全进展，或主动策略在合理预算区间没有优势 |
| H2 | 绑定配置 epoch、新鲜度和来源的执行门减少过期/错配证据授权 | unsafe release、stale-authorized、config mismatch exposure、误拒率 | 检查增加但仍可被已有旧证据/并发状态绕过，或进步完全来自保守 HOLD |
| H3 | LLM 对非 LLM active-evidence/workflow 基线有额外价值，且超过推理开销 | 增量安全进展/业务 utility、token/API/墙钟成本、故障面 | 相同工具与预算下收益无统计/实际意义，或额外成本大于改善 |
| H4 | 事务故障恢复对 CSI 双侧配对有实际作用 | partial activation exposure、恢复成功率、恢复时延 | 不注入故障时才成立，或简单单侧执行器已达到同等结果 |
| H5 | 共享领域契约可跨主/次用例复用，而决策与安全语义需用例化 | 第二用例 contract coverage、adapter complexity、无效约束比例 | 主用例抽象导致 CSI 无法准确表达，或策略规则无法迁移且需大改核心 |

H1/H2/H3 分别检验主动证据、可靠执行和 LLM 增量，不得合成一个笼统的“Agent 有效”结论。

## 4. 环境和证据等级

| 等级 | 环境 | 可支持的结论 | 当前优先级 |
|---|---|---|---|
| D0 | 可控 lifecycle simulator + 合成状态/证据 + 故障注入 | 策略、预算、状态机、重试、崩溃恢复的因果比较 | 必做首步 |
| D1 | 静态 channel/CSI/beam trace 重放 | 模型、场景和测量序列上的离线有效性 | D0 后接入 |
| D2 | 有状态无线仿真，动作改变未来 KPI/资源/证据 | 闭环策略收益、漂移应对、等待和切换损失 | 主要无线证据 |
| D3 | 系统级或软件 RAN/RF simulator | network/system KPI 映射、软件集成与时序 | 研究贡献需要时二选一 |
| D4 | 授权硬件在环或真实测量 | 指定设备和场景的实测成本、可运行性 | 增强项，不作首版阻塞 |

静态重放不能单独支撑“动作导致性能恢复”的因果结论。RF simulator 不等于真实传播测量；软件 RAN 集成也不等于运营商现网部署。论文应报告证据等级和对应的外推边界。

## 5. Episode 生成和数据隔离

### 5.1 Episode 单位

一个 episode 表示一个生命周期决策窗口，而不是一条 CSI 样本。最小序列为：

```text
固定初态与隐藏场景真值
  -> 向策略投影授权 ObservationView
  -> 策略提出 query / evaluate / prepare / commit / hold / reject / rollback
  -> 执行器校验并扣预算
  -> 仿真环境推进，产生有时效的新证据或故障
  -> 部署后 KPI 验收 / 恢复
  -> evaluator 用隐藏真值与事件日志评分
```

Episode 需保存 scenario、candidate digest、设备/网络 profile、初始 active function/epoch、预算、测量成本、各时钟、工具结果引用、故障计划、真实状态转移和最终业务后果。Agent 输入、私有真值、故障计划、评估标签分文件/进程隔离。

### 5.2 数据划分

禁止按随机 CSI row 切分后声称泛化。按不可拆的组划分：

- 场景/地图/小区或区域；
- 连续移动轨迹和采集 session；
- UE/radio profile、码本和校准版本；
- 模型家族/权重版本；
- 故障因果模板、消息顺序和错误组合；
- 时间段和标签生成机制。

测试集要包含未见过的组合，但保持每种故障含义可解释；不能把仅改 seed 的同一轨迹复制到 train/test。开发集可选阈值、提示词和成本参数，确认性测试集只能用于最终比较。

### 5.3 时间和成本

同时保存 `sim_time`、`wall_time`、`observed_at`、`arrived_at`、`decision_at`、`effective_at`。LLM/API 等待期间无线状态是否继续变化由实验配置明确；主实验优先让模拟环境按仿真时钟推进，再用墙钟记录 planner latency。每项工具成本分解为无线测量资源、UE 推理/能耗代理、BS/UE 算力、通信字节、模型下载、API/token 和时延，避免不同量纲被一个未说明权重吞掉。

## 6. 基线和公平比较

全部策略共享同一个 scenario tape、候选集、动作接口、工具实现、确定性 validator、fallback、测量价格表和时间推进规则。每个策略获得等价的可见证据、累计预算与决策时限；不允许 Agent 查询 simulator oracle。

| 编号 | 策略 | 要回答的问题 |
|---|---|---|
| B0 | 固定阈值 + hysteresis + 周期监测 | 工程规则基准 |
| B1 | 变化检测/序贯检测（如 CUSUM 或 P19 受控感知适配） | 已知统计监测/观测选择能力 |
| B2 | 确定性 DAG/状态机工作流 | 组合执行是否需要语言模型 |
| B3 | 非 LLM 主动证据策略，按预定义 VOI/成本或 bandit/动态规划规则选测量 | 证据经济学本身带来的收益 |
| B4 | 单网络侧 LLM planner + UE 确定性 validator + 公共 executor | LLM 规划的增量价值 |
| B5 | 证据assurance LLM 基线/结构化 gate 基线 | 与 WirelessOpsAgent/AgentSpec 邻近方法的公平比较 |
| B6 | 双侧 planner/UE Agent，仅在 D0/C4 之后 | UE 侧自主规划是否必要 |
| B7 | 全知 offline oracle | 可达上界；明确不可部署 |
| B8 | Always measure / exhaustive scan | 资源无限或过量采集的成本参考 |

B1 至少在其适用的观测假设下调参；不能用未经调参的“假统计基线”压低对照。B5 用同一个确定性 gate 来隔离 evidence assurance 机制。B6 不是默认主要系统。B7 的真值只在 evaluator side。

LLM 报告固定的 provider/model snapshot 或 endpoint ID、system prompt hash、temperature、tool schema、token/API 价格、重试和超时。不同策略重复 LLM stochastic runs；相同 episode/seed 的策略运行顺序随机化，资源隔离。

## 7. 故障与场景矩阵

| 维度 | 因素水平/事件 | 检验目标 |
|---|---|---|
| 模型/接口 | digest 错配、schema/quantization/latent 不同、文件损坏 | manifest 和兼容性守卫 |
| 配置 | codebook/measurement set/antenna calibration/coordinate system epoch 更新 | 旧 evidence 是否撤销 |
| 观测 | KPI 延迟、乱序、缺失、置信区间宽、来源冲突、measurement cost 上升 | 选测、等待或拒绝 |
| 设备资源 | 温度/内存/电量/算力阈值越界；prepare 后余量变化 | TOCTOU 和本地拒绝 |
| 控制消息 | PREPARE/READY/COMMIT/ACK 丢失、重复、延迟、重放 | 幂等、重试和未知提交处理 |
| 执行阶段 | 下载失败、测试失败、准备后崩溃、单侧激活、planner timeout | 恢复与回退 |
| 部署后 | KPI 退化、环境再漂移、短期噪声触发振荡 | 后验收、hysteresis、churn |
| 并发 | 多 UE 争抢共享 decoder/GPU/measurement slot | reservation 无超卖、冲突排序 |
| 隐私/授权 | 超用途数据、原始 CSI 请求、拒绝或只可返回摘要 | 不越过数据权限边界 |

先有单故障用例定位性质，再设计 pairwise/组合故障压力集；不直接用全笛卡尔积制造大量难解释 episode。每种组合都记录因果顺序和预先定义的故障标签。

## 8. 指标及定义

### 8.1 安全与进展

- **Unsafe release / episodes**：至少含一次不满足 schema、兼容性、epoch、新鲜度、资源或授权约束却被 commit 的 episode 数 / 全部 episode 数。
- **Unsafe release / releases**：违规 commit 数 / 所有 commit 数；与 episode 分母并报，避免静默提高拒绝率粉饰风险。
- **Safe progress**：窗口内存在经 oracle 判定有益且可安全发布机会的 episode 中，按时完成安全发布的比例。
- **Missed beneficial update**：有益候选和可行窗口存在，但因无必要等待/错误拒绝/超时未完成的比例。
- **Configuration mismatch exposure**：错配 active duration、受影响推理/数据数；事件级和时长/样本量级都报告。
- **Recovery**：故障至已验证兼容模型或 fallback 恢复服务的 sim-time 和 wall-time 分位数；只有日志状态变化不算恢复。

### 8.2 业务、证据、振荡和开销

- **业务效用**：按用例报告模型指标及下游 KPI 曲线/违约；如有合成综合效用，权重在测试前定义并同时公布不加权分量。
- **Evidence cost**：各类测量次数、无线资源、字节、UE/BS compute、能耗代理和费用分别统计；同预算结果用 Pareto/frontier 对比。
- **Churn**：单位时间激活/回退/重复补测次数、无收益切换数及切换间隔。
- **Planner overhead**：token、API 成本、墙钟 p50/p95/p99、timeout/error/retry。
- **模型指标**：按任务报告 top-K/beam hit rate、误差/校准或 CSI NMSE/correlation；这些只表示模型性能。
- **无线指标**：有对应执行链时报告 BLER/BER、throughput、latency、feedback overhead、resource usage，不以离线 NMSE 推断无线收益。

除总成功率外，还按 failure family、evidence quality/freshness、设备 profile 和预算层分层，报告分母和有效 episode 数。

## 9. 统计分析和样本量

1. **Pilot**：只用 development scenarios 估计各指标基准率、策略方差、episode 内相关性和故障发生率，检查 simulator 是否能区分策略。
2. **确认性设计**：预先登记一个主要结局（建议为安全约束下的 safe progress 或单位预算业务效用）、主要比较、方向性假设、错误率和最小有意义差异。
3. **配对比较**：所有策略共享相同的 scene/episode/seeds；对策略差值做 paired analysis，减少场景难度方差。
4. **置信区间**：按独立 scenario/trajectory cluster bootstrap；稀有 unsafe 事件补充精确二项区间。不能把同一轨迹的时间点当独立样本。
5. **多重比较**：预先指定主比较；其他 baseline、切片和消融作为次要分析，使用 Holm 或控制 FDR，并报告未经校正与校正结果。
6. **样本数**：pilot 后按最小有意义差异和期望检验功效做功效分析。先定义停止规则和失败 episode 是否保留，避免固定拍脑袋 N。
7. **报告**：给出 effect size、CI、完整分母、排除项和策略运行失败率；不只给 p-value，也不把“未显著”解释成等价。

LLM 非确定性下，策略重复次数要和 episode 数分开报告。若成本过高，先减少提示词搜索并锁定模型，再报告少量 LLM 重复的精度限制；不得复用测试集挑最佳 prompt。

## 10. 消融和敏感性分析

最小消融：去掉 freshness/epoch gate；去掉预算成本；固定测量序列；去掉 post-activation acceptance；关闭 fallback；关闭资源 reservation；仅用模型 KPI 不用业务 KPI；用 LLM 直接执行而跳过公共 validator（只在隔离模拟器的反事实安全测试中运行）；单 Agent 与双侧 planner 比较；改变测量成本、证据到达延迟、环境漂移速度和可用预算。

改变合成效用权重、unsafe 代价和 SLA 窗口做敏感性分析。重点观察结论是否依赖任意权重。分层用例不可用同一 safety semantic 强行汇总；例如 PairManifest 的兼容性故障不应计入单侧 beam 的配对指标。

## 11. 实验阶段及进入门

| 阶段 | 目标 | 进入下一阶段前的证据 |
|---|---|---|
| E0 控制面 | 修正 schema、动作边界、预算、状态机、event log、evaluator | replay 可重复；validator 单测覆盖硬约束；所有阶段可恢复状态有日志和可测试结果 |
| E1 策略比较 | B0-B3 同基础设施下比较证据选择 | 测量确实有成本；不测/全测都有可观察代价；至少一段预算/漂移区间出现有效 Pareto 取舍 |
| E2 波束主用例 | 绑定真实/公开 beam 模型或测量，接上场景外与 KPI 验收 | 数据许可和 split 固定；baseline 可运行；模型输出会影响 simulator 的结果路径 |
| E3 LLM 增量 | B4/B5 公平比较并计推理成本 | 先定义任务组合；LLM 具有策略组合自由度，且同一 validator/工具/预算 |
| E4 CSI 双侧 | 测 PairManifest 和部分提交恢复 | candidate weights/data/model-preprocess contract 可复现；定义双端生效点与恢复假设 |
| E5 系统或 RAN | 选择 5G-LENA 或 OAI RFsim 路线 | 模型动作到网络 KPI 有代码映射；时钟和资源开销已计；平台版本固定 |

若 E1 不能形成非平凡预算—风险权衡，不进入 E3 调 prompt。若 E3 LLM 相对 B1-B3 无可复现增益，保留工具架构和确定性执行器，将研究结论收缩为非 LLM LCM。

## 13. 现阶段不能声称的内容

在相应阶段完成前，不声称：已复现第三方论文代码；数据/权重许可允许再发布；仿真等价真实 RF；软件 RAN 等价商用 O-RAN；模型 NMSE 改善必然提高吞吐；LLM/双 Agent 优于非 LLM；故障注入覆盖生产故障分布；所有无线用例共用同一配对/安全语义。
