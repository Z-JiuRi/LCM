# 文档整理说明与原章节对照

> 整理日期：2026-10-25。整理以分篇、归类和导航整合为主，不做实质性删减，不重新判定论文结论或更改实验协议。

## 整理规则

1. 保留原正文中的独有论述、表格、公式、代码示例、数值、来源与限制；原编号用于追溯。
2. 旧总报告的正文分篇保留；仅剩跳转用途的旧文件已删除。论文清单与检索记录集中在相关工作。
3. 原目录和重复导航换成新的阅读入口；不同报告的分析视角保留来源标记，不强行合成一个结论。
4. 同一主题按职责分工：分析解释“为什么”，相关工作记录“已有证据”，项目草案定义“候选方案”，通用工程参考保存“示例怎么做”。
5. 全部整理前的项目自维护 Markdown 已保存到本次操作的本地临时备份；仓库中的本文件与各专题保留长期可读的章节映射。
