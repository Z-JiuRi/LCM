## 7. 与 LCMAgent 的关系

<a id="q7-1"></a>

### 7.1 映射：AutoML 结论 → 本项目问题

| AutoML/agent 结论 | LCMAgent 对应问题 | 迁移判断 |
|---|---|---|
| 预算必须由执行器强制（`2608.07303`） | 证据采购预算、控制延迟预算由谁保证 | **可直接迁移**：预算不变量应落在确定性执行器，而非 LLM 规划器 |
| 决策级评估缺席（`2602.22442`） | "何时回滚/何时换模型"这类中间决策如何评分 | **高价值迁移**：本项目的核心正是决策，而非最终精度 |
| 增益多来自热启动先验（`2606.21641`） | agent 规划是否只是复述人工调好的默认策略 | **必须迁移为消融**：去掉先验后 agent 是否仍有增益 |
| 经典优化器在连续参数上更强（`2603.24647`） | 阈值、调度权重、重校准步长该由谁决定 | **分工迁移**：连续参数用 CMA-ES/BO；agent 只做离散结构决策 |
| harness 冗余（`2609.40303`） | 三平面 + 多 agent 的架构是否自带增益 | **必须迁移为基线**：minimal-harness 单 agent 基线 |
| 泄漏与静默失败（`2610.14115`、`2610.04927`） | 过期证据复用、跨场景洞见注入 | **同构风险**：需要证据来源与新鲜度的显式建模 |
| 控制延迟摧毁纠正优势（`2609.14517`） | 慢速规划 / 快速回退的分层是否必要 | **外部支持**：且必须在有延迟条件下评测 |

> 注：`2609.14517` 已有逐篇解读（[P05 L2 Trigger](../../相关工作/论文详解/P05_L2Trigger.md)），本文只引用其延迟—过渡策略结论，不重复解读。本节其余文献在本仓库尚无逐篇解读。

<a id="q7-2"></a>

### 7.2 不可照搬的三点

1. **试错成本结构不同**。AutoML 每次 trial 花的是算力；无线侧每次"试"花的是空口资源、业务 SLA 乃至用户可见故障。AutoML 的 safe-exploration 假设在这里不成立，证据获取本身要建成本模型。
2. **目标维度不同**。AutoML 优化单一（或少数）指标；LCM 面对硬 SLA、安全门、双端一致性，属于约束满足而非单目标最小化。
3. **动作可逆性不同**。AutoML 候选失败即丢弃；无线侧的激活、配对、切换可能不可回退或回退有代价。因此"回退路径"是设计一阶对象，不是异常处理。

<a id="q7-3"></a>

### 7.3 三条可迁移原则

- **P-1 预算不变量执行器化**：任何"agent 在有限预算下更聪明"的主张，只有在预算由非 LLM 组件强制时才可信。
- **P-2 决策级评估先于结果级评估**：先证明中间决策（采哪个证据、换哪个模型、是否等待）优于基线策略，再谈端到端 KPI。
- **P-3 先验消融是必需项**：默认策略、热启动配置、领域知识注入必须作为单独变量被移除过一次。
