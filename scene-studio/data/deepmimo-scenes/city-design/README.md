# 四公里不规则混合城区原型

日期：2026-10-26。当前是用户确认的 4×4 km、16 km² 版本，替代原来的十公里规则网格。文件名保持稳定，已有俯视图、浏览器数据及实例化场景均更新到四公里版本。

## 已生成内容

- `city-topview.png`：6710×6905 像素带注记全城俯视图。
- `city-topview-clean.png`：6400×6400 像素无标注图，1.6 像素/米。
- `city-topview-preview.png`：会话内使用的全图预览。

- `assembled-city.view.json`：浏览器用的世界坐标轮廓与来源，非三维面模型。

- `assemble_city.py`：源几何读取、建筑布置、检查、导出和渲染。
- `compact_layout.py`：四公里主干路、功能片区、非等距街坊和保留组团定义。

## 当前实测与限制

36 组来源、1,317 个源几何资产，放置 13,838 个建筑几何实例到 619 个可建地块。7,635 个实例由源邻域变换选入，6,119 个用于重组填充，84 个属于整体保留排列的组团：Boston 53 个、ASU 31 个。全部为原尺寸刚体实例，不是 13,838 栋独立原始建筑。

局部世界坐标为米制 X 东、Y 北、Z 上；范围 0–4000 米。每个源资产有原对象索引和原点，每个实例有旋转与平移，未缩放。源材料来自 2026-10-25 官方预览缓存；完整源工程、材质及再分发许可审查未完成。

新路网不采用统一横纵间距，各大区递归切出不同方向与大小的街坊。保留组团仅整体旋转和平移，筛除了源预览中相互重叠等不适用对象，不是原始场景无损复制。组团内部通道是根据间隙推断的新增设计，不能当作已验证的现实道路。

二维检查中，建筑投影之间面积重叠、越出对应地块、侵入道路车行面、侵入公园均为 0；相交面积不大于 0.01 平方米不计。统计基于舍入前几何，导出保留毫米或更高变换精度。

建筑基底约 3.0088 平方公里，约全域 18.8%；道路车行面并集约 2.4969 平方公里，绿地扣除道路约 1.0859 平方公里。其余为院落、退界、步行空间和未填满地块。尚未达到旧方案提出的 25%–35% 试验密度目标。

道路、地块、公园和平地是合成设计；树点只作画面符号，高度阴影只是显示效果。建筑功能是规划分配。没有引入源地形、材料、TX/RX 或源信道；没有完整室内、标准 InF 或 RMa 场景。道路路由、建筑入口、三维拓扑、电磁材料和跨区 RT 尚未验证，尚未计算新信道。

## 复现

在仓库根目录运行：

```sh
uv run --with numpy --with scipy --with pillow --with shapely python output/deepmimo-scenes/city-design/assemble_city.py
```

仅重新渲染已保存的实例化场景：

```sh
uv run --with numpy --with scipy --with pillow --with shapely python output/deepmimo-scenes/city-design/assemble_city.py --render-only
```

在本目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766/city-viewer.html`。直接双击 HTML 可能因本地文件安全限制无法读取 JSON。

种子为 26102604，使用 Python 3.14、NumPy、SciPy、Shapely、Pillow 和 macOS Hiragino Sans GB 字体；不同依赖版本或字体可能影响几何运算/图像输出。当前来源清单和构建日志用于检查，不是无线实验结果。
