# 城市级几何拼接规划草案

日期：2026-10-26。当前目标已由用户确定为 **$4\times4\,\mathrm{km}$，共 $16\,\mathrm{km}^2$**。已生成非等距路网的几何拼接原型与全城俯视图；未完成最终三维、道路路由、材料与 RT 验收，未重新计算信道。

## 1. 本轮改变

用户认为旧十公里方案过大，且七乘七主网格过于规整。新方案不是把十公里模型缩小，也不是裁出九个方格，而是在四公里范围内重新规划道路和街坊，保留原建筑的米制尺寸。

- 去掉等间距横纵干道：用非等距、不同走向的弯曲干道和集散路组织城区，没有统一的七乘七或三乘三网格。
- 各片区内部沿自身道路方向递归切分，形成不等长街坊、楔形地块、错位路口和局部近矩形街坊。不是把所有街道随机扭曲，也不要求完全不存在直角路口。
- 主中心使用一组筛查后的 Boston 建筑，保留它们的原始相对位置；校园同样保留一组筛查后的 ASU 建筑。两者只做整体刚体变换。
- 高层中心、次级商务中心、中高层组团、中层社区、紧凑低层社区、低层居住、校园、就业园区、混合商业、绿地均有分布，不为每种类型单独切一个规则方块。

新城区仍是虚构研究场景，不声称复制现实 Boston 或其他城市。源建筑功能没有官方用地标签时，新功能只属于项目设计分配。

## 2. 当前区域与来源

坐标范围为 $[0,4000]\times[0,4000]\,\mathrm{m}$，X 向东、Y 向北。下面的位置是布局锚点，不是行政区中心。

| 区域 | 大致位置 | 来源与组合 |
|---|---|---|
| 主中心 | 中部，约 $(2070,2180)$ | `boston5g_3p5` 作为核心；外围以 Philadelphia、Sydney 与混合素材过渡 |
| 次级商务中心 | 东北，约 $(3040,2970)$ | Chicago、Seattle、Edinburgh、Montreal 等；不再复制两个大型副中心 |
| 中高层组团 | 主中心东南、北侧 | Singapore、Nanjing、São Paulo、Shanghai 等，搭配中层体量 |
| 中层社区 | 北部及各中心之间 | Cairo、Rio、Mumbai、Madrid、Indianapolis、Sankt-Peterburg、Warszawa、Huanggang 等 |
| 紧凑低层社区 | 西部及南部，两处不相邻 | New York 0、Miami、Taito、Kyoto；局部保留细小街坊 |
| 低层居住社区 | 西南及西北两处 | Los Angeles、Dallas、Santa Clara、Charlotte、Denver、Toronto 等 |
| 大学与研究园区 | 西北，约 $(1010,3270)$ | `asu_campus_3p5` 保留原排列的筛查后组团，周围补充中层和混合建筑 |
| 就业与服务园区 | 东南，约 $(3620,700)$ | Phoenix、Oklahoma 与混合素材；不是已经确认的厂房/仓库数据 |
| 混合商业街 | 主要道路沿线和各功能区接边 | Austin、Cape Town、Guangzhou、Bogotá 等 |
| 公园与绿廊 | 北部公园、东侧绿廊及社区小公园 | 新增合成设计，不伪称 DeepMIMO 原始公园；道路可有解释地跨越绿地 |

36 组主选来源本轮均被使用，6 组备用未强行加入。完整、可复制的场景 ID 在[素材筛查记录](../../../output/deepmimo-scenes/city-design/expanded-source-screening.json)中；各来源的实际实例数量见[本轮清单](../../../output/deepmimo-scenes/city-design/assembled-city-manifest.json)。

这里的“类型齐全”指上述室外城市形态。没有声称具备完整室内楼层、标准 InF 厂房、RMa 乡村、机场或港口。UMa/UMi 需要结合新的站点部署判定，LoS/NLoS 是链路状态，不是预涂的功能区标签。

## 3. 怎样保留 Boston 的不规则形态

Boston 保留 53 个筛查后的源几何对象，统一旋转 $-17^\circ$ 并平移到主中心；ASU 保留 31 个对象，统一旋转 $14^\circ$ 并移到西北。组内对象的相对位置不另行随机排列，建筑没有缩放。

原始预览存在重叠投影、重复对象和部分过大或非单一有效轮廓，因此“保留”不是整个原始场景无损搬运。重叠对象采用保留较大对象的规则筛除，被排除的源对象索引记录在清单中。三维面仍来自被保留对象的官方预览。

两组内部的浅色通道依据建筑间隙推断，是新增设计，不是从 DeepMIMO 导出的已核实道路。外围干道接到组团周边，不能以这一步推断内部每条通道都能通车。

其他片区保留部分源邻域排列，并用完整源建筑补齐地块；地块边缘不截断建筑。原型会复用同一几何资产，不能把实例数当作互不重复的真实建筑数量。

## 4. 已生成统计与检查

以下为当前原型的实际计算值，不沿用旧十公里规划预算：

| 项目 | 当前值 |
|---|---:|
| 外包范围 | $4\times4\,\mathrm{km}$ |
| 总面积 | $16\,\mathrm{km}^2$ |
| 使用来源 | 36 组 |
| 使用源几何资产 | 1,317 个 |
| 建筑几何实例 | 13,838 个 |
| 可建地块 | 619 个 |
| 建筑基底面积 | 约 $3.0088\,\mathrm{km}^2$，约 18.8% |
| 道路车行面并集面积 | 约 $2.4969\,\mathrm{km}^2$ |
| 大型绿地扣除道路面积 | 约 $1.0859\,\mathrm{km}^2$ |
| 建筑投影面积重叠 | 0 对 |
| 建筑越出对应可建地块 | 0 个 |
| 建筑与道路车行面相交 | 0 个 |
| 建筑与公园相交 | 0 个 |

重叠与相交检查忽略不大于 $0.01\,\mathrm{m}^2$ 的数值微小区域，面积来自导出舍入前几何。建筑投影不重叠不等于完成三维拓扑、建筑入口或道路路由验收。其余面积包括院落、退界、步行空间和未填满地块，不全是公园。

旧方案曾提出 25%–35% 的全域建筑基底试验目标，本轮没有达到，也不把旧目标当作已实现指标。当前先交付用户要求的更小、非等距布局；是否继续加密由实际视觉和实验需求决定。

## 5. 证据边界与后续

- 官方预览缓存为 2026-10-25 保存的研究材料；来源条目、对象索引、源原点和刚体变换均保留在导出场景中。
- 36 组主选在缓存目录中的 `hasRtSource` 均为 0；这不等于没有任何几何，但不能据此声称获得完整可复现 RT 源工程。几何许可、材料和完整工程仍待逐项核实。
- 路网、地块、绿地和统一平坦地面属于合成设计。树点及高度阴影只是渲染表现，不是树木电磁模型或光照仿真结果。
- 下一步应检查道路入口、连通和交叉口、组团过渡、建筑语义及三维拓扑，再部署基站/UE 和重算信道。几何平滑不要求转角信道被人为平滑。
