#### 22.14.1 证据等级、阅读提醒和版本校准

- **原始 README/API**：可以验证项目*声称的*运行机制；不意味着所有部署的可靠性被独立验证。对源码协议敏感时应将 `main` URL 固定到 commit SHA。
- **arXiv 预印本**：论文有日期、可复核的作者实验声明，但并非自动得到第三方同行评审确认；文中“最优”“首次”等表述保留作者语境。
- **作者博客**：可以观察工程迭代轨迹，因数据/硬件/随机性/数据集不同，不能与其它博客中的相对提升百分比横向排序。
- **社区整理**：是发现资料的入口，不是研究成果数量与可信度的统计普查；同名、重复 fork 与技术独立性必须人工核实。
- **本报告研究局限**：检索了多个项目官方文档、论文摘要或 HTML 正文及多篇作者博客；未下载执行所有仓库，也未对论文 PDF 全部附录、代码审计、训练日志做全面独立复现。不应把公开声称中的数据视为本报告复现实验。
