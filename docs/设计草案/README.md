## 状态标记

- **仓库事实**：由当前工作树文件或已提交实验记录支持。
- **已有工作**：由所引用论文、标准或外部仓库支持；不意味着本项目复现。
- **候选设计**：当前建议，需评审、实现或实验验证。
- **待决策**：需由数据、pilot 或工程约束决定，不能在代码中默认为已解决。

草案随证据更新。每项从“候选”转为“已决定/已实现/已验证”时，记录对应决定、代码、测试或实验运行标识。
