# LCMAgent 扩展检索与核验记录

> 日期：2026-10-20。对应 [专题综述](../分析文档/LCMAgent/README.md)、[43 项 BibTeX](参考文献.md) 和 [逐篇解读目录](论文详解/README.md)。本记录说明范围和来源，不是穷尽性系统综述，也不是实验复现报告。

## 1. 问题与本次扩展

前轮 25 篇论文的定位偏向双侧 CSI。此次保留原编号，新增 P26–P40，共 15 篇，覆盖波束模型选择/适配、真实多模态数据、位置辅助波束的漂移、信道图/神经定位、神经接收机、部署后恢复、统计监测、事后风险校准及轻量在线适配。

调查的核心不是“有没有标题包含 Agent”，而是五个问题：管理什么功能、由谁观测和控制、哪些证据需要成本、已有监测/更新机制多强、何种失败尚需在本项目验证。单侧推理与跨端管理不矛盾；实际波束切换、预测模型切换、测量/码本变更分别登记。

## 2. 检索路径与公开查询词

采用原有题名/DOI 复核 → 非 CSI 直接近邻 → 原始论文/标准 → 方法基础与数据来源 → 版本与书目交叉核验。未向外部搜索发送本地未公开设计段落。代表性公开查询为：

```text
AI model selection monitoring beam management 5G Advanced
model adaptation lifecycle management AI native 5G 6G
statistical AI ML model monitoring interference prediction
DeepBeam / DeepSense 6G / predictive beamforming geographical positioning
spatial temporal generalization CSI neural positioning
channel charting / DeepRx / DeepWiPHY
VERITAS AI native receiver retraining
LightTune forward only online fine tuning link adaptation
post hoc conformal prediction reliable wireless communications
AI ML air interface Release 19 standardization generalization
```

技术结论优先使用论文原文、作者公开稿、出版社/官方会议及标准文件。书目同时核对 arXiv 的题名/作者/版本和 DOI 注册元数据；不把检索摘要、文件名或 DOI 中的年份单独作为正式卷期证据。不满足来源准入要求的材料不进入文献库；未读全文时不作“原文没有”的否定结论。

## 4. 阅读与复现边界

A 表示已核读相关全文/章节，不表示已经逐式推导、运行代码或审计全部图表；B 为摘要/原始记录级；C 为原有材料或核验受限。40 篇论文不是 40 篇全部完成同等深度全文精读。每篇分别标记，不以统一“精读完成”掩盖缺口。

P03/P04 的完整算法与实验、P13/P14/P17/P25 的部分实现细节仍应优先补读；P14 的正式出版信息尚待确认。对这些文献，详解保留已证实内容并给出具体精读检查项，不填写想象的网络结构、统计量或收益。

本次没有运行第三方论文代码、下载全量数据集或产生任何新无线性能结果。推荐的波束 + CSI 验证、候选基线和风险—成本曲线均为后续实验计划，不是已完成结果。

## 5. 交付校验口径

校验范围为：43 个唯一引用键、40 篇论文与 3 份非论文解读、综述编号覆盖、BibTeX 语法/字段、相对链接、Markdown 围栏及补丁空白。文献解析成功不意味着所有网页永远可访问，也不等于引用中的技术结论获得独立实验复现。

本次实际通过：BibTeX 解析器读取 43 个唯一条目；必需字段、DOI/arXiv/年份格式检查；43 个综述条目与引用键、独立解读一一对应；242 个本地链接可解析；围栏与来源筛选检查；`git diff --check`。阅读深度为 A 20 项、B 18 项、C 5 项，包含标准与讨论材料。
