## 2. 问题、对象与前提

VERITAS 直接回答已训练 AI-native 接收机在新环境是否仍优于传统接收机。模型在训练分布表现好并不能确保信道类型、移动速度和时延扩展变化后的可靠性，因此需要部署后测量与恢复，而不是永远相信离线验收。

## 3. 方法与工作流程

Monitor 将导频经 triplet-loss 网络映射到类簇，用 KNN 邻居及簇中心/半径判断 OOD；任何近邻投票为 ID 即判 ID，而不是普通多数投票。疑似变化后临时启用 TradRx，并行比较比特概率直方图中间不确定区的计数，估计谁的 BER 更差，不需要当前真比特来作比较。之后才触发有限再训练；“复核不用真值”不等于“训练也无需标签”。

## 4. 实验证据、结果与局限

摘要给出三种变化检测准确率 99%、97%、78%，比较器平均准确率 86%、93.3%、94.8%。正文结论另报告 true OOD detection 的时延扩展值 69%，不能与 78% 不加区分地混写。平均数还掩盖某些高速度/EbN0 组合下比较器失效。实验使用 Sionna 生成的 3GPP TDL 信道；并行参考处理不是无成本真值，且未由此证明真实网络任意漂移下可用。

## 5. 对 LCMAgent 的具体影响

这是 LCMAgent 扩展到接收机时的强直接基线。若只让 LLM 调用检测、参考复核、再训练三个工具，方法新意不足。可以进一步检验多证据预算分配、何时不更新、候选适配验收和故障恢复，但必须共享同样监测/参考处理能力，不能把 P36 的有力基线削弱成一个阈值。
