## 2. 问题、对象与前提

TR 38.843 研究 NR 空口中 AI/ML 的框架、用例、评估与潜在规范影响。核验版本为 V19.0.0（2025-09，Release 19），不是声称截至检索日的最新版本。它不是“CSI 模型压缩报告”：波束管理和定位增强同样是主体内容。Technical Report 的研究结果、选项和潜在影响，不应改写成终端已必须实施的规范要求。

## 3. 方法与工作流程

阅读顺序应为 §4 的 AI/ML 阶段、LCM flavours、模型标识、附加条件、场景专用模型和协作层级，再进入 §5 的三个用例。§6.3 区分波束测量集合 Set B 与预测目标 Set A，以及不同预测条件；§6.4 单独研究定位的数据收集、泛化、微调、输入缩减与非理想标签。§7 的规范影响及测试讨论必须与 §6 的评估结果分开解释。

## 4. 实验证据、结果与局限

这是多个研究方案及评估的汇总，不存在可以无条件摘录的“AI 统一提升百分比”。波束目标集合、CSI 反馈配置、定位真值与各方仿真假设不同。仅看某张性能图而不看配置，很容易把测量减少、模型预测增益和额外输入优势混在一起。

## 5. 对 LCMAgent 的具体影响

LCMAgent 的上位管理对象应是无线 AI 功能，而非固定 encoder/decoder pair。框架层已有监测、更新、切换和回退议题，创新需要落到有成本的证据选择、具体配置绑定和可执行恢复。双侧 CSI 的配对约束不能直接套给单侧波束预测器；相反，单侧推理也可能由网络控制并依赖跨端测量。
