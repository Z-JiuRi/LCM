## 15. 评估方法

<a id="s15-1"></a>

### 15.1 系统对照

至少比较以下方案：

1. 静态固定模型；
2. 只按照离线精度选择模型；
3. 只由 BS Agent 决策；
4. BS Agent + UE 确定性 Runtime；
5. BS Agent + UE 轻量 Agent；
6. 规则系统 + 固定测试流水线；
7. BS/UE 双 Agent + 独立验证器。

<a id="s15-2"></a>

### 15.2 主要研究假设

#### H1：双侧本地验证能够减少错误发布

在 BS 获得的信息不完整或过期时，UE 侧本地验证应减少：

- 不兼容模型激活；
- UE 资源超预算；
- 半完成双侧切换；
- 本地隐私策略被绕过。

#### H2：证据驱动的双 Agent 能减少不必要补测

在相同测试预算下，Agent 应通过识别最有价值的缺口，达到更高的有效发布率；或者在相同有效发布率下减少测试次数和测试成本。

#### H3：净收益决策优于精度贪心决策

当模型精度、反馈开销、推理成本、切换中断和回退风险同时存在时，净收益策略应比“选择精度最高模型”减少无效切换。

#### H4：分层 Agent 优于对称双 LLM

完整 BS Agent + 轻量 UE Runtime 应在资源、时延、可解释性和错误隔离方面优于 BS/UE 两侧各部署完整 LLM。

<a id="s15-3"></a>

### 15.3 指标

#### 决策正确性

- 有效发布率；
- 错误发布率；
- 错误模型配对率；
- 本地拒绝正确率；
- 过期证据使用率；
- 不必要拒绝率。

#### 生命周期性能

- 模型切换成功率；
- 半完成事务数量；
- 切换中断时长；
- 回退次数；
- 模型退化持续时间；
- 部署后验收通过率；
- 跨小区模型连续性。

#### 系统开销

- 测试次数；
- 补测成本；
- Agent 调用次数；
- Agent 端到端时延；
- 模型传输开销；
- 数据收集开销；
- UE 计算、存储和功耗开销。

#### 无线业务效果

- 吞吐量；
- BLER；
- CSI 反馈开销；
- 推理时延；
- 用户业务中断；
- 旧场景性能损失；
- 跨场景泛化性能。

## 16. 实验场景设计

<a id="s16-1"></a>

### 16.1 基础场景

固定：

- 选定用例的 2-4 个候选模型；
- 该用例的传统或非 AI 基线；
- 2 类 UE 能力；
- 2-3 个信道场景；
- 固定模型版本和测试工具；
- 固定模型配对关系；
- 固定发布窗口和测试预算。

<a id="s16-2"></a>

### 16.2 必须覆盖的异常

- 目标模型证据缺失；
- UE 内存不足；
- 输入输出格式不匹配；
- BS 与 UE 模型版本不一致；
- 一端准备成功、另一端失败；
- 证据在测试期间过期；
- 小区切换导致场景漂移；
- 在线微调数据不足；
- Agent API 失败；
- 模型性能超过退化阈值；
- 回退模型不可用；
- 竞争发布事务同时发生。

<a id="s16-3"></a>

### 16.3 动态状态变化

在 Agent 规划和工具调用期间改变：

- UE 能力；
- 当前模型版本；
- 目标小区；
- 数据权限；
- 维护窗口；
- 模型撤销状态；
- 网络负载；
- 可用回退版本。

验证 Agent 是否能够在共同激活前重新检查状态，而不是沿用旧计划。
