## 内容维护边界

- **分析文档**维护概念、判断、研究假设和跨材料推论；引用文献明细，不再复制整份书目。
- **相关工作**维护文献、检索、核验状态和第三方代码来源；论文自述与独立复现分开。
- **设计草案**维护 LCMAgent 候选架构与实验协议；当前范围和未决事项集中在[材料映射与决策门](设计草案/材料映射与决策门.md)。
- **工程参考**保留通用 AutoML 示例；采用其中设计时，另外记录项目决定与代码依据。
- **标准文件**保留原 PDF 和条款解读；项目协议与字段不能写成标准要求。

同一主题的不同来源若存在口径差异，保留来源日期和适用范围。整理只调整归属与导航，不替代文献复核或实验验证。
