## 18. 阅读路线与分阶段学习计划

<a id="s18-1"></a>

### 18.1 研究者的三阶段阅读顺序

**第一阶段：理解传统 AutoML 及正确的实验方法（建议优先阅读）**

1. Hutter et al. 开放教材《AutoML: Methods, Systems, Challenges》[R01]；
2. Auto-WEKA（CASH 问题）[R02]；
3. auto-sklearn 与 2.0（元学习、集成及 hands-free）[R03], [R16]；
4. Hyperband / BOHB（资源调度）[R04], [R05]；
5. AutoGluon、FLAML、AMLB（强系统与公平评测）[R07], [R10], [R13]。

目标：能够解释“为何一个模型搜索器即使很聪明，也会因不正确的验证协议而给出错误结论”。

**第二阶段：研究 ML Agent 的实验闭环**

1. ReAct、Reflexion（工具动作/反馈）[R35]–[R36]；
2. MLAgentBench、DSBench、MLE-bench（定义 agent 的能力与难度）[R20], [R32], [R30]；
3. DS-Agent、AutoML-Agent、AutoKaggle（案例推理与多步骤流程）[R21], [R22], [R24]；
4. AIDE、R&D-Agent、ML-Master（代码树搜索、研究循环与记忆）[R26], [R27], [R33]。

目标：能构建一个具备 `Plan → Act → Evaluate → Reflect` 和真实任务/算力约束的基础 agent。

**第三阶段：前沿训练型 Agent 与研究挑战**

1. ML-Agent（RL 训练 ML 实验策略）[R28]；
2. DeepAnalyze（复杂数据科学任务的课程式训练）[R29]；
3. MLGym、MLRC-Bench（开放科学问题上的能力边界）[R37], [R43]；
4. TabRepo、TabArena、TabPFN（历史经验与表格基础模型）[R12], [R19], [R18]；
5. 结合本报告[第 17 章](研究机会.md#s17)设计小规模、可复现实验。

目标：从“搭一个 Agent Demo”升级为“能提出可证伪贡献和系统性评测的研究”。

### 20.4 建议首个可运行研究 Demo

选择 8–12 个表格分类数据集，保持固定划分与统一环境。设置 30 分钟每任务的建模预算；实现三组：**AutoGluon baseline**、**FLAML baseline**、**LLM planner + 受控 AutoML 引擎**。Agent 只能读取 DataProfile 和 CV 结果，能选择模型搜索方案/预算，但不能修改评测器。按 3 seed 统计：验证 AUC、首个有效模型时间、最终测试 AUC、token 成本、GPU/CPU 小时和失败率。若 Agent 在同等成本下没有明确收益，就不应追加多 Agent、RAG 和 RL 等复杂模块。先把研究问题定义清楚，才能知道复杂度值得不值得投入。

<a id="s20-5"></a>

### 20.5 最后结论

**传统 AutoML 提供可信的受控优化内核；Agentic AutoML 扩展任务理解、假设构造、实验编排、代码改造和失败修复；训练型 Agent 则尝试让这些决策经验进一步跨任务学习。三者相互补充。**

学术研究上最值得发力的是：低成本策略学习、结构化跨任务记忆、严格的预算对照、泄漏与安全基准，以及可证伪的研究假设—实验执行闭环。产业实践上更值得优先投入的是：**一个强基线、一个可信评估器、一个受限工具编排 Agent、一个不可篡改的实验记录系统**。只有这些基础设施可靠，端到端自治才可能从可看的演示进化为可用的生产能力。
